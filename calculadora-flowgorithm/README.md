# Calculadora em Flowgorithm

Projeto de uma **calculadora desenvolvida em Flowgorithm**, utilizando conceitos fundamentais de lógica de programação, estruturas condicionais, variáveis e operações matemáticas.

O projeto foi desenvolvido como parte dos estudos de **Ciência da Computação**, com o objetivo de praticar a construção de algoritmos e a resolução de problemas através de fluxogramas.

---

## Sobre o projeto

A calculadora funciona a partir de um **menu de opções**, onde o usuário escolhe qual operação deseja realizar.

A partir da escolha, o algoritmo direciona o fluxo para a operação correspondente, solicita os valores necessários, realiza o cálculo e apresenta o resultado.

O projeto contém **20 operações diferentes**, incluindo operações matemáticas, funções numéricas e comparações.

##  Funcionamento

O fluxo principal do programa pode ser resumido da seguinte maneira:

```text
             ┌──────────────┐
             │    INÍCIO    │
             └──────┬───────┘
                    ↓
          ┌───────────────────┐
          │ Escolher operação │
          └─────────┬─────────┘
                    ↓
        ┌─────────────────────────┐
        │     Qual operação?      │
        └───────────┬─────────────┘
                    ↓
       ┌────────────┴────────────┐
       ↓                         ↓
  Ler valores              Executar cálculo
       │                         │
       └────────────┬────────────┘
                    ↓
          ┌──────────────────┐
          │ Mostrar resultado│
          └────────┬─────────┘
                   ↓
              ┌─────────┐
              │   FIM   │
              └─────────┘
```

O fluxograma utiliza uma sequência de decisões para identificar a opção escolhida pelo usuário e executar o cálculo correspondente.

##  Ferramenta utilizada

**Flowgorithm**

O projeto foi construído utilizando a representação visual de algoritmos através de fluxogramas, permitindo visualizar de forma clara o fluxo de execução do programa.

##  Objetivo do projeto

O principal objetivo foi transformar conhecimentos teóricos de **lógica de programação** em um algoritmo funcional.

Além das operações básicas de uma calculadora, o projeto explora diferentes tipos de operações para praticar decisões, expressões matemáticas e manipulação de dados.

Este projeto representa uma das etapas da minha evolução no aprendizado de programação:

> **Entender o problema → construir a lógica → transformar em algoritmo → testar a solução.**
