## Repetição de Número em C

Este projeto é um programa simples desenvolvido em linguagem C que solicita ao usuário um número e a quantidade de vezes que ele deseja repeti-lo. Em seguida, o programa exibe o número informado na tela pelo número de vezes escolhido.

## Funcionamento
O programa:

Solicita ao usuário um número inteiro.

Pergunta quantas vezes o número deve ser repetido.

Utiliza uma estrutura de repetição while para exibir o número na quantidade de vezes informada.

##  Exemplo de execução
Digite um numero: 7
Quantas vezes deseja repetir? 5
7
7
7
7
7

 ## Conceitos utilizados
Variáveis do tipo int

Entrada de dados com scanf()

Saída de dados com printf()

Estrutura de repetição while

Incremento de variável com contador++

Biblioteca stdio.h

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar os conceitos básicos da linguagem C, principalmente entrada e saída de dados e estruturas de repetição.
